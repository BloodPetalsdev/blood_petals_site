Bem-vindo ao Motion Studio ✿

  1. Importar FBX: arraste seu modelo ou clique em “Importar FBX”. Ele fica no seu computador.
  2. Selecionar um osso: clique nos pontos rosa do modelo ou no painel esquerdo.
  3. Criar poses: gire o osso, clique em “Keyframe”, avance o tempo e crie outra pose.
  4. Reproduzir: pressione Espaço ou ▶ para visualizar a interpolação.
  5. Rig feminino e saia: importe o SweaterUniformRIGGED.fbx e ative IK. Em Saia inteligente, ative a influência das coxas e grave a pose; não altera o esqueleto original.
  6. Shading e texturas: abra Shading (Texturas no celular), escolha a malha no seletor, toque em “Criar material” e depois selecione uma imagem do dispositivo. É possível editar cor, opacidade e mapas.
  7. Rig Assist IK: abra Pose → Rig Assist para mover mãos/pés por controle, ajuste a direção do cotovelo/joelho e grave os keyframes nos ossos originais. É inspirado no Rigify, não converte o FBX num Rigify verdadeiro.
  8. Exportar: use “Exportar animação .FBX”. O conversor precisa de um servidor com Blender.
O personagem de demonstração serve para aprender. Para exportar seu próprio personagem para a Unity, importe primeiro o FBX original da Ayame. O projeto JSON inclui as imagens importadas, mas não o arquivo FBX original.

Servidor Blender ✿

Para exportar FBX pelo navegador, conecte um servidor autorizado com Blender. O HTML não usa o Blender instalado no seu computador. O endereço e o token são fornecidos pelo administrador da equipe.

A chave fica apenas nesta sessão do navegador. Não compartilhe essa chave em repositórios públicos.

Como gerar um FBX para o Blood Petals?

Aplicativo Windows (mais fácil)

  1. Instale o Blender no computador.
  2. Crie uma animação na timeline, com os keyframes necessários.
  3. Abra a aba Exportar e clique em Exportar animação .FBX.
  4. Se solicitado, selecione o arquivo blender.exe instalado no Windows.
  5. Escolha onde salvar o arquivo FBX. Na Unity, selecione o FBX e configure Rig → Animation Type → Legacy.

Versão HTML (sem servidor Blender)

  1. Clique em Exportar prévia .GLB e baixe o modelo animado.
  2. Abra o Blender: File → Import → glTF 2.0 e selecione o GLB.
  3. Use File → Export → FBX, com Bake Animation ativado e Add Leaf Bones desativado.
  4. Importe o FBX na Unity como Legacy e teste a animação com o rig original.

O botão FBX direto da versão HTML requer um servidor com Blender configurado. O HTML sozinho não converte FBX. A conversão GLB → FBX pode modificar hierarquias ou configurações; valide os ossos e clips na Unity.
