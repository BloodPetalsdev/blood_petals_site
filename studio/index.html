Bem-vindo ao Motion Studio ✿

  1. Importar FBX: arraste seu modelo ou clique em “Importar FBX”. Ele fica no seu computador.
  2. Selecionar um osso: clique nos pontos rosa do modelo ou no painel esquerdo.
  3. Criar poses: gire o osso, clique em “Keyframe”, avance o tempo e crie outra pose.
  4. Reproduzir: pressione Espaço ou ▶ para visualizar a interpolação.
  5. Exportar: use “Exportar animação .FBX”. O conversor precisa de um servidor com Blender.
O personagem de demonstração serve para aprender. Para exportar seu próprio personagem para a Unity, importe primeiro o FBX original da Ayame. O projeto JSON não contém o arquivo FBX.
CONVERSOR FBX

Servidor Blender ✿

Para exportar arquivos FBX pelo celular, conecte um servidor privado que execute o Blender. O endereço e o token são fornecidos pelo administrador da equipe.

A chave fica apenas nesta sessão do navegador. Não compartilhe essa chave em repositórios públicos.
